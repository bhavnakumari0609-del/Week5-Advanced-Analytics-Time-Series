# Week 5 - Advanced Analytics and Time-Series Analysis

## Project Overview

This project demonstrates the practical application of advanced analytics and time-series analysis techniques using Python.

The project analyzes daily sales data to identify trends, rolling patterns, weekly seasonality, anomalies, and forecast future sales using baseline forecasting methods.

## Objectives

- Analyze sales data over time
- Identify overall sales trends
- Calculate a 7-day rolling average
- Analyze day-of-week seasonality
- Detect unusual sales observations
- Split data into training and testing sets
- Build Naive and Seasonal Naive forecasting models
- Evaluate forecasting performance using MAE, RMSE, and MAPE
- Visualize actual and forecasted sales

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
